# 📚 Média da Sala – Java
Este é um programa simples em Java que calcula a média das notas de uma turma de alunos. O usuário informa quantos alunos estão na sala e insere as notas um por um. Ao final, o programa exibe a média da turma.

## 🧠 Conceitos utilizados
- Estrutura de repetição do...while

- Leitura de dados com Scanner

- Variáveis e operações matemáticas

- Entrada e saída no console

## 💡 Exemplo de uso
``` bash

Digite quantos alunos tem na sala: 3  
Digite a nota dos alunos: 7  
Digite a nota dos alunos: 8  
Digite a nota dos alunos: 9  
A media da sala e 8.0
